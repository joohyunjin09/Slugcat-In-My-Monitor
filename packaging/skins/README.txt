Slugcat in My Monitor - DMS skin folder
========================================

Place each Dress My Slugcat sprite set in its own subfolder here, then open
the app and press F2. Use "Reload sprites" if the editor was already open.

Example:

skins/
  MySkin/
    metadata.json       optional; id, name, and author are displayed
    head.png
    head.txt
    face.png
    face.txt
    body.png
    body.txt
    arm.png
    arm.txt
    hips.png
    hips.txt
    legs.png
    legs.txt
    tail.png
    tail.txt
    pixel.png
    pixel.txt

Every part is optional, but each included PNG must have a matching TXT atlas
descriptor. The editor can apply a complete set or mix individual parts.

This release does not include Rain World, Dress My Slugcat, or community skin
assets. Only add files that you own or have permission to use.
