# Third-party test assets

The local `.local-test-assets/` directory may contain Dress My Slugcat template
files downloaded from the upstream `1.6.6` release for compatibility testing.
It is intentionally excluded from version control.

- Upstream: https://github.com/MatheusVigaro/DressMySlugcat/releases/tag/1.6.6
- Archive: `ModTemplate.zip`
- SHA-256: `538B807E581FA876F8405F98257E4C8C0264228C419764F049A30560B9E927A5`
- Retrieved: 2026-08-23

The upstream guide describes these assets as templates intended for creating
custom sprites, but the repository does not currently include an explicit
root license. Do not redistribute the local fixture without confirming terms.
